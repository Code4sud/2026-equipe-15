Backend — Node.js + Express (depuis le 19/11, la stack Python/FastAPI est abandonnée).

Rôle : recevoir un Rapport des Possibles (PDF), en extraire les scores des
graphiques et les métiers sous forme de JSON avec leurs sources, et plus
tard dialoguer avec une IA et générer des restitutions personnalisées
(texte, audio, fiches interactives).

Lancer :
    cd backend
    npm install
    npm start          # API sur http://localhost:8000
    npm test           # tests de bout en bout (PDF fictif « Rdv FICTIF »)

Auth : API_TOKEN dans backend/.env (voir .env.example). Si défini, chaque
requête exige « Authorization: Bearer <API_TOKEN> ». Vide = mode dev ouvert.

│   │   ├── metiers.js      # champ des possibles : zones et métiers (lignes en gras)
│   │   └── analyzer.js     # analyserRapport() : orchestration -> JSON d'analyse

├── tests/
│   ├── fixtures/genererRapportFictif.js   # génère un PDF fictif en pur JS (« Rdv FICTIF »)

└── storage/
    ├── uploads/            # PDF déposés (ignoré par git, .gitkeep seulement)
    └── outputs/            # analyses JSON générées (idem)

Routes actuelles :
    POST /report/upload      : dépose un PDF (multipart, champ « fichier »), retourne l'analyse (201)
    GET  /report             : liste les identifiants d'analyses
    GET  /report/{id}        : analyse complète (JSON avec sources)
    GET  /report/{id}/scores : les 3 graphiques (RIASEC, aptitudes, HEXACO) avec leurs sources
